# eSignature System - Quick Start Guide

## For Users

### How to Complete an SOP with Signature

1. **Read the SOP**
   - Open assigned SOP from dashboard
   - Review all content thoroughly

2. **Take the Competency Test**
   - Click "Take Competency Test"
   - Answer all questions
   - Submit test

3. **Sign if You Pass**
   - If score ≥80%, signature modal appears automatically
   - See your score and success message
   - Read the declaration
   - Type your full name exactly as it appears in your profile
   - Check the "I agree" checkbox
   - See preview of your signature
   - Click "Sign & Submit"

4. **Wait for Admin Verification**
   - Your assignment shows "Awaiting Admin Signature"
   - Dashboard indicates signature pending
   - Admin will be notified to counter-sign

5. **Completion**
   - Once admin counter-signs, status changes to "Completed"
   - You'll see "Fully Signed" badge
   - Training certification is official

### If You Fail the Test
- No signature required
- Can retake the test
- Must pass before signing

## For Admins

### How to Counter-Sign

**Option 1: Email Notification**
1. Receive email: "Counter-Signature Required: [User] completed [SOP]"
2. See user details, test score, and their signature
3. Login to system

**Option 2: Dashboard**
1. See blue alert card on dashboard
2. Shows count of pending counter-signatures
3. Click to go to Counter-Sign page

**Counter-Signing Steps:**
1. Click "Counter-Sign" in sidebar OR
2. Go to "Counter-Sign" page
3. See list of pending signatures with:
   - Staff member name
   - SOP title and version
   - Test score
   - User's signature
   - Timestamp
4. Click "Counter-Sign" button
5. Modal opens with:
   - Admin declaration
   - Input for your full name
   - Agreement checkbox
   - Signature preview
6. Type your name exactly
7. Check "I agree"
8. Click "Counter-Sign & Complete"
9. Done! Staff member's training is certified

### Who Can Counter-Sign
- **Any admin** can counter-sign any completion
- Not limited to the admin who originally assigned the SOP
- System tracks which admin counter-signed

## Quick Reference

### Declarations

**User Declaration:**
> "I confirm that I have thoroughly read the documentation and answered all questions honestly and to the best of my ability"

**Admin Declaration:**
> "I confirm that the assignee has read the documentation and answered all questions honestly and to the best of their ability"

### Status Badges

| Badge | Meaning |
|-------|---------|
| Pending | Not started |
| In Progress | User is reading |
| Awaiting User Signature | Test passed, needs user sign |
| Awaiting Admin Signature | User signed, needs admin sign |
| Fully Signed | Both parties signed |
| Completed | Fully verified and certified |

### Where to Find Things

**Users:**
- Sign after passing test (automatic modal)
- Check status: Dashboard → Your assignments
- View history: Progress → Signature indicators

**Admins:**
- Counter-sign: Sidebar → Counter-Sign
- View pending: Admin Dashboard → Blue alert card
- Staff signatures: Staff Management → [User] → Assignments table
- Full history: Test Results Detail → Signature section

## Important Notes

### Security
- All signatures timestamped
- IP addresses recorded
- Signatures are immutable (cannot be edited)
- Full audit trail maintained

### Version Control
- Each SOP version requires new signatures
- Old signatures stay with old versions
- New versions start fresh
- Complete separation maintained

### Compliance
- Dual verification ensures accountability
- Legal electronic signatures
- Suitable for regulatory requirements
- Complete audit trail for inspections

## Troubleshooting

**Q: I passed the test but didn't see a signature modal**
- Refresh the page and try again
- Check if assignment shows "Awaiting User Signature"
- Contact admin if issue persists

**Q: My signature won't submit**
- Verify you typed your full name correctly
- Make sure checkbox is checked
- Check for JavaScript errors in browser console

**Q: Admin hasn't counter-signed yet**
- Email may have been delayed
- Admin may not have checked dashboard
- You can send them a reminder

**Q: Can I change my signature after submitting?**
- No, signatures are permanent for compliance
- If there's an error, contact admin

**Q: What if the assigning admin left the company?**
- Any admin can counter-sign
- System not limited to original assignee
- Signature still valid
